# जय अहोई माता (Jai Ahoi Mata)

The āratī of Ahoī Mātā, in Hindi (`hi`).

- **Text** (`text.txt`): Aarti Mala (page image i-335), checked against Drik Panchang. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** `audio/ambey-bhakti/`: Ambey Bhakti (YouTube `ecr8xZKBBOo`, "ॐ जय अहोई माता - Om Jai Ahoi Mata - Ahoi Mata Ki Aarti - श्री अहोई माता की आरती - Ahoi Ashtami 2026"). Starts from MMS (`aligned.md`); the verses the checks flag are on the to-check list. A draft (it plays only with Audio timing on): MMS could not time every verse it sings (some it scored too low, others it placed nowhere: `aligned.md`); they are left untimed rather than guessed.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Jai Ahoi Mata) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 7 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
