# बिल्वाष्टकम् (Bilvāṣṭakam)

Shelf: हिन्दू धर्म › स्तोत्र › भगवान शिव › बिल्वाष्टकम् (`library/hinduism/stotra/shiva/bilvashtakam/`, work id `bilvashtakam`). The hymn of the bilva leaf offered to Śiva, in Sanskrit (`sa`): eight numbered ślokas, the Kāśī śloka (unnumbered, as the source has it), the phalaśruti and the closing words.

## Sources

- **Word meanings:** written for this library, in `library/glossary/sa.json`.
- **Recording:** Sounds of Isha, "Bilvashtakam | Trigun | Shiva | Mantra" (YouTube `6rJExE8HGVg`), in `audio/sounds-of-isha/`; the speech-quality copy is in scriptures-data at `hinduism/stotra/shiva/bilvashtakam/audio/sounds-of-isha/6rJExE8HGVg.opus`.

## Files
The folder's format: `tools/works/README.md`.
- `text.txt`: the settled text, one item per śloka.
- `source/owner-text.txt`: the owner's text as pasted.

## Structure
One part. Items `sh1`–`sh7`, `kashi`, `sh8` (type `shloka`), `phala` (`phalashruti`), `iti`. Each item is its own section. Topics: the bilva leaf (ślokas 1–5), the bilva tree (6–8), the phalaśruti. Item ids are permanent.
