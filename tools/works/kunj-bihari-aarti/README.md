# आरती कुंजबिहारी की (Aarti Kunj Bihari Ki)

The āratī of Śrī Kṛṣṇa as Kuñjabihārī (who roams the groves of Vraja), in Hindi (`hi`).

- **Text** (`text.txt`): Drik Panchang, "Kunj Bihariji Ki Aarti" (the book has no copy of it). Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** `audio/kumar-vishu/`: Kumar Vishu (कुमार विशु), the "Aarti Collection" jukebox (YouTube `rI-DXgiHALU`), the track 26:18–30:16 (1578–1816 s); every verse sung, in the text's order. The starts come from the transcript (`transcripts/`, with hand-checked starts in `fixes.md`), to be set by ear.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Aarti Kunj Bihari Ki) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 4 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
