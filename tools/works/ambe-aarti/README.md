# जय अम्बे गौरी (Jai Ambe Gauri)

The āratī of the Mother, Ambā (Durgā), in Hindi (`hi`).

- **Text** (`text.txt`): ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, pp. 177–178, under the heading "आरती श्री दुर्गा जी की"), checked against Drik Panchang and Aarti Mala; three lines (stanzas 2, 4 and 12) as Anuradha Paudwal sings them, in Drik Panchang's words. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** `audio/anuradha-paudwal/`: Anuradha Paudwal, the "Om Jai Jagdish Hare Aarti Sangrah" jukebox (YouTube `sd31yGqZFlA`), the track 15:12–22:28 (912–1348 s); every verse sung, in the text's order. The starts come from the transcript, to be set by ear.
- **Poet:** the last stanza names शिवानन्द स्वामी (Shivanand Swami).

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Jai Ambe Gauri) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 12 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
