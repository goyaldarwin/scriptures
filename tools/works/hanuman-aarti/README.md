# आरती कीजै हनुमान लला की (Āratī Kījai Hanumāna Lalā Kī)

The āratī of Śrī Hanumān, in Hindi (`hi`): the āratī of the Sundarakāṇḍa work, taken from it unchanged (`[take sundarkand …]`), so a correction there reaches this work at the next export.

- **Text** (`text.txt`): The Sundarakāṇḍa work (`tools/works/sundarkand/reconciliation.md`).
- **Meanings:** The Sundarakāṇḍa's own (`meanings/<lang>/scriptures.json` takes them).
- **Recordings:** `audio/ashwin-pathak/`: the Sundarakāṇḍa's recording, its timings taken for these verses (`source.json` → `take`).

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`); the Mānas's own types (`cau`, `cha`, `do`, `so`) where a text uses them. The folder's format: `tools/works/README.md`.

## Introduction
The readers' introduction (`intro` in `library/index.json`, shown in ⓘ About this work) states only what these support:
- The text itself and its signature in the last stanza (our text and meanings, from the Sundarkand work).
- tools/works/sundarkand/README.md: the aarti sung after the Hanuman Chalisa at the end of the Sundarkand.
