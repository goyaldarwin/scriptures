# आरती श्री साई गुरुवर की (Aarti Shri Sai Guruvar Ki)

The āratī of Sāī Bābā of Shirdi, sung on Thursdays (गुरुवासर), in Hindi (`hi`).

- **Text** (`text.txt`): ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, p. 134), checked against Drik Panchang and Aarti Mala. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.
- **Poet:** the last stanza names Sāīdāsa ('साईदास' आरती को गावै).

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Aarti Shri Sai Guruvar Ki) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 5 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
