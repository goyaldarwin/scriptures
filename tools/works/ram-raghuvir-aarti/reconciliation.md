# Reconciliation: ऐसी आरती राम रघुबीर की करहि मन

## Witnesses
- **Drik Panchang (base)** (`hinduism/aarti/rama/ram-raghuvir-aarti/printouts/drikpanchang/shri-rama-raghuvira-aarti.html`): the refrain couplet, then five stanzas of four lines, the refrain's first line marked after each. The owner's books have no copy of this āratī, so the page is the only witness.

The rule: keep the base; correct it only where it is clearly wrong. The library's writing standard (docs/PLAYBOOK.md §3): an āratī's verse has no comma (a pause within a line is a space); the refrain (टेक) is shown once; stanzas numbered (॥१॥).

| Place | Base | Ours | Why |
|---|---|---|---|
| every stanza | lines ending with a comma or nothing, the last ॥ | । and ॥N॥ | The standard. |
| within lines | commas (सर्वगत, सर्वदा · बसत, इति · पावक, सतोगुण · सनकादि, श्रुति, शेष, शिव · देवरिषि, अखिलमुनि · करै सोइ तरै, परिहरै) | spaces | The standard. |
| the refrain cue | ऐसी आरती राम रघुबीर की करहि मन॥ after each stanza | not written | The refrain is shown once, first. |
| stanza 1, line 1 | रुप | रूप | रुप (short u) is a typing slip for रूप ("form"). |
| stanza 2, line 3 | सन्शय | संशय | The page types every nasal before a consonant as न्; न्श is not a Hindi spelling (संशय, "doubt"). |

Kept as the base has them: रघुबीर, करहि, हरण, दुखदुन्द, बासना, निजबोधगत, छीजै, श्रीरमण, सन्तोषकारी, बीजहारी, दशवर्तिका, सतोगुण, प्रकासं, अर्पि नीराजनं जगनिवासं, पर्यंक, श्रीरामराया, नहिं, देवरिषि, तत्त्व-दरसी, सोइ, and the page's hyphens.
