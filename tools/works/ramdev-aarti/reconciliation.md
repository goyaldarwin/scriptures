# Reconciliation: ॐ जय श्री रामादे

## Witnesses
- **The book (base):** ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, Haridwar, 2000), p. 161; scriptures-data `hinduism/chalisa/books/aarti-chalisa-sangrah/` (page image i-160), read on the page image. Its order: the refrain, रूप मनोहर, विष्णु रूप, दुःख दलजी का, नाव सेठ की.
- **Drik Panchang** (`hinduism/aarti/ramdev/ramdev-aarti/printouts/drikpanchang/shri-ramdev-aarti.html`): the same āratī, in the same order and the same words, each printed line broken in two.

The rule: keep the book; correct it only where it is clearly wrong. The library's writing standard (docs/PLAYBOOK.md §3): an āratī's verse has no comma; each line as the book prints it; the refrain (टेक) is shown once; stanzas numbered (॥१॥).

| Place | Book | Ours | Why |
|---|---|---|---|
| stanza numbers | none | ॥१॥ … ॥४॥ | The standard. |
| after the refrain and every stanza | ॐ जय'' | (not shown) | The refrain cue; the refrain is the first item (टेक). |

Kept as the book has them: every word; Drik Panchang does not differ from the book in any word.

## Readings settled
- **pad 3**, सरजीवन भाण को (भाण a name or for भाणेज, sister's son): a name, Bhāṇ, as printed. The Rāmdev Chālīsā's seventh parchā (Sugnā's son revived) would fit 'nephew', but no dictionary or source gives भाण for भाणेज, and the web searches found no account that settles it; the printed word stands.
