# Reconciliation: जय जय गिरिधारी प्रभु

## Witnesses
- **Drik Panchang (base):** Lord Giridhari Aarti (`hinduism/aarti/krishna/giridhari-aarti/printouts/drikpanchang/lord-giridhari-aarti.html`): the refrain and nine stanzas, each half-line printed on its own line, with the refrain cue "जय जय गिरिधारी प्रभु, जय जय गिरिधारी" after every stanza.
- **The book:** none. The āratī is not in ५१ चालीसा संग्रह आरतियों सहित (`hinduism/chalisa/books/aarti-chalisa-sangrah/`) or the other booklets; Drik Panchang is the only witness.

The rule: keep Drik Panchang; correct it only where it is clearly wrong. The library's writing standard (docs/PLAYBOOK.md §3): an āratī's verse has no comma (a pause within a line is a space); each printed line is a line, ending । and the stanza's last ॥N॥; the refrain (टेक) is shown once.

| Place | Base | Ours | Why |
|---|---|---|---|
| after every stanza | जय जय गिरिधारी प्रभु, जय जय गिरिधारी। (refrain cue) | (not shown) | The refrain cue; the refrain is the first item (टेक). |
| every line | the printed commas (also inside lines: गोपालक, गोपेश्वर; अति अघ, अघहारी; शेष, महेश, सरस्वति) | (none) | The standard. |
| stanza numbers | none | ॥१॥ … ॥९॥ | The standard. |
| stanza 1, line 3 | वन्शीधर | वंशीधर | Drik Panchang types the anusvāra as न् (here before श, where no class nasal stands); the word is वंशी. |
| stanza 2, line 4 | जग-मन्गल-कारी | जग-मङ्गल-कारी | The same slip before ग; the class nasal, as Drik Panchang writes रञ्जन in stanza 4. |
| stanza 4, line 4 | दिति-सुत-सन्हारी | दिति-सुत-संहारी | The same slip before ह: the word is संहार. |
| stanza 5, line 1 | टिट्टिभ-सुत-सन्रक्षक | टिट्टिभ-सुत-संरक्षक | The same slip before र: the word is संरक्षक. |
| stanza 5, line 2 | रक्षक मन्झारी | रक्षक मञ्झारी | The same slip before झ; the class nasal. |
| stanza 7, lines 1–2 | अघ-बक-बकी / उधारक तृणावर्त-तारी। | अघ-बक-बकी उधारक । / तृणावर्त-तारी । | The line break is misplaced: every stanza's first and third lines have 12 mātrās and its second and fourth 10 (जय गोविन्द दयानिधि / गोवर्धन-धारी); अघ-बक-बकी उधारक is 12 and तृणावर्त-तारी 10, and उधारक ("deliverer of Agha, Baka and Bakī") belongs with the names it governs. |
| stanza 7, line 4 | कन्स-मुक्तिकारी | कंस-मुक्तिकारी | The same slip before स: the name is कंस. |

Kept as the base has them: the hyphens, बनवारी, द्रौपदि-दुखदारी, गौतम-तिय, मन्मथ मन्मथ मोहन (मन्मथ is the word itself, Kāma), बिधि, गुन, कल कीरति-बिस्तारी, चितहारी.

## Readings settled
- aarti.pad9, नारायण: the poet naming himself, as the meaning has it; the third-person verb (चाहत, "he longs") needs a third-person subject, and the closing stanza is the āratī's signature, as in other āratīs; the hi glossary's नारायण already lists both senses (the Lord / the poet of this āratī).
