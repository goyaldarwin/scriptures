- **Text** (`text.txt`): Drik Panchang, "Brahmacharini Mata Aarti" (drikpanchang.com/lyrics/aarti/navdurga/brahmacharini/devi-brahmacharini-aarti.html); the āratī is not in the book. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: पद (stanza, `pad`). The āratī has no refrain (टेक): the witness prints none. The folder's format: `tools/works/README.md`.
