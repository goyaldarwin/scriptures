# भज गोविन्दम् (Bhaja Govindam)

Shelf: हिन्दू धर्म › स्तोत्र › भगवान श्रीकृष्ण › भज गोविन्दम् (`library/hinduism/stotra/krishna/bhaja-govindam/`, work id `bhaja-govindam`). Ādi Śaṅkarācārya's Moha-mudgara, in Sanskrit (`sa`): the refrain-verse, the twelve verses of the Dvādaśa-mañjarikā, the fourteen of the Caturdaśa-mañjarikā and the teacher's closing verses, 31 in all.

## Files
The folder's format: `tools/works/README.md`.
- `text.txt`: the settled text, one item per verse, in the recording's order.

## Structure
One part. Items `sh1`–`sh31` (type `shloka`), each its own section. Topics: the refrain (1), the Dvādaśa-mañjarikā (2–13), the Caturdaśa-mañjarikā (14–27), the teacher's closing verses (28–31). Item ids are permanent.
