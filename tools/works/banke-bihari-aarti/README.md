# श्री बाँकेबिहारी तेरी आरती गाऊँ (Shri Banke Bihari Teri Aarti Gaun)

The āratī of Kṛṣṇa as Bāṅke Bihārī of Vṛndāvana, in Hindi (`hi`).

- **Text** (`text.txt`): Drik Panchang, Shri Banke Bihari Ki Aarti; none of the printed booklets has it. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Shri Banke Bihari Teri Aarti Gaun) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 5 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
