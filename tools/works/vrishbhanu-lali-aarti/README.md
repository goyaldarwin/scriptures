# आरति श्रीवृषभानुलली की (Aarti Shri Vrishbhanu Lali Ki)

The āratī of Śrī Rādhā, the dear daughter of Vṛṣabhānu, in Hindi (`hi`).

- **Text** (`text.txt`): Drik Panchang, "Devi Radhika Aarti" (the book has no copy of it). Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Aarti Shri Vrishbhanu Lali Ki) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 4 stanzas of four lines.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
