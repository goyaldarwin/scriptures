# आरति करत यसोदा प्रमुदित (Aarti Karat Yasoda Pramudit)

A pada of Yaśodā performing the āratī of the child Kṛṣṇa, in Hindi (`hi`; its words are Braj).

- **Text** (`text.txt`): Drik Panchang, "Shri Yashodalala Aarti" (the book has no copy of it). Every choice: `reconciliation.md`.
- **Poet:** the signature line names कृष्णदास (stanza 4).
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: पद (stanza, `pad`); the source prints no refrain, so there is no टेक (`tek` is declared, as in every āratī, but unused). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Aarti Karat Yasoda Pramudit) › one section (`aarti`) › verses: 4 stanzas of four lines.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3").
- **Topics:** one, the āratī's opening words. **Reading plans:** none.
