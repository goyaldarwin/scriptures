# मैया शारदा तोरे दरबार आरती नित गाऊँ (Maiya Sharda Tore Darbar Aarti Nit Gaun)

The āratī of Mother Śāradā, in Hindi (`hi`), opening with a dohā.

- **Text** (`text.txt`): ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, pp. 270–271), checked against Drik Panchang. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: दोहा (`do`, the opening dohā), टेक (refrain, `tek`, shown once although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Maiya Sharda Tore Darbar) › one section (`aarti`) › verses: the opening dohā (`aarti.do1`, type `do`), the refrain (`aarti.tek`, type `tek`) and 6 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the dohā and the refrain have none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
