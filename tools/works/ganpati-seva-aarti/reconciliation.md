# Reconciliation: गणपति की सेवा मंगल मेवा

## Witnesses
- **Drik Panchang (base):** `aarti/shree-ganesh/ganapati-seva/ganapati-seva-aarti` (`hinduism/aarti/ganesha/ganpati-seva-aarti/printouts/drikpanchang/ganapati-seva-aarti.html`): the only printed witness. The book (५१ चालीसा संग्रह आरतियों सहित, Randhir Prakashan; scriptures-data `hinduism/chalisa/books/aarti-chalisa-sangrah/`) does not print this āratī. The page prints the refrain (its first four lines) once and the cue "गणपति की सेवा मंगल मेवा..." after every stanza.
- **For a doubtful reading only:** the text as other sites print it, found by web search: Shubh Panchang (shubhpanchang.com, "ganpati-ki-seva-mangal-meva") and InstaAstro (instaastro.com, "ganpati-seva-aarti"). Bhakti Bharat prints Drik Panchang's text and counts with it.

The rule: keep Drik Panchang's text; correct it only where it is clearly wrong. The library's writing standard (docs/PLAYBOOK.md §3): an āratī's verse has no comma (the page's commas are dropped); the refrain (टेक) is shown once; stanzas numbered (॥१॥).

The page's stray । after गावैं is dropped. |
| stanza numbers | none | ॥१॥ … ॥९॥ | The standard. |

Settled by the web witnesses, kept as the page has them: देव बंधु सब गान करैं (stanza 4) and दिन दोपारा दूर परैं (stanza 3), both as Shubh Panchang and InstaAstro print them. Kept as the page has them: रिद्धि-सिद्धि, अरु / अरू (stanzas 1, 3; the page has both), चढ्या, उपज्या, सुन्यो, पगथंभा, शराप, लियो जन्म गणपति प्रभु जी (a short line, as printed), गणपति की पूजा पहले करने से (a long line, as printed).
