# जय भैरव देवा (Jai Bhairav Deva)

The āratī of Baṭuka Bhairava, in Hindi (`hi`).

- **Text** (`text.txt`): ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, p. 73), checked against Drik Panchang and Aarti Mala. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** `audio/t-series-bhakti-sagar/`: T-Series Bhakti Sagar (YouTube `EAS1Pc85Pto`, "Om Jai Bhairav Deva [Full Song] - Aartiyan"). Starts from MMS (`aligned.md`); the verses the checks flag are on the to-check list.
- **Poet:** the last stanza names धरणीधर (Dharanidhar).

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Jai Bhairav Deva) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 6 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
