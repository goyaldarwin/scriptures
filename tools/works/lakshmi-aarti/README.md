# ॐ जय लक्ष्मी माता (Om Jai Lakshmi Mata)

The āratī of Lakṣmī (Mahālakṣmī), in Hindi (`hi`), in the widely sung version (Drik Panchang's and Aarti Mala's), as Anuradha Paudwal sings it; the Randhir book prints another wording of the same āratī.

- **Text** (`text.txt`): the version Anuradha Paudwal sings, from Drik Panchang and Aarti Mala, with the words it shares with ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, pp. 190–191) as the book spells them. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** `audio/anuradha-paudwal/`: Anuradha Paudwal, the "Om Jai Jagdish Hare Aarti Sangrah" jukebox (YouTube `sd31yGqZFlA`), the track from about 33:18 to 38:48 (2328 s); the stanzas from 34:26 (2066 s), every verse sung, in the text's order. The starts come from the transcript, to be set by ear; the transcript has no line of the opening refrain, whose start is a guess to check.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Om Jai Lakshmi Mata) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 7 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
