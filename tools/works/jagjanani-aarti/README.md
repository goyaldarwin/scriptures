# जगजननी जय जय (Jagjanani Jai Jai)

The āratī of the Devī as Mother of the world (Śrī Devījī kī Āratī), in Hindi (`hi`).

- **Text** (`text.txt`): Drik Panchang, "Shri Devi Ji Ki Aarti" (the book has no copy of it). Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** `audio/anuradha-paudwal/`: Anuradha Paudwal, "Aarti Vol. 2" (a jukebox, YouTube `faxIif-3F8o`), the track 19:07–30:54. The starts come from the transcript, with hand-checked ones in `fixes.md`; to be set by ear.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Jagjanani Jai Jai) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 13 stanzas of two lines.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
