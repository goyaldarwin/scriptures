# जय जय अम्बे जय कात्यायनी (Jai Jai Ambe Jai Katyayani)

The āratī of Devī Kātyāyanī, one of the nine forms of Durgā (Navadurgā), in Hindi (`hi`).

- **Text** (`text.txt`): Drik Panchang, "Katyayani Mata Aarti" (the book has no copy of it). Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: पद (stanza, `pad`); the source prints no refrain, so there is no टेक (`tek` is declared, as in every āratī, but unused). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Jai Jai Ambe Jai Katyayani) › one section (`aarti`) › verses: 5 stanzas of four lines.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3").
- **Topics:** one, the āratī's opening words. **Reading plans:** none.
