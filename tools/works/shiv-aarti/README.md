# ॐ जय शिव ओंकारा (Om Jaya Śiva Oṅkārā)

The āratī of Śiva, in Hindi (`hi`), in Anuradha Paudwal's version.

- **Text** (`text.txt`): Four written witnesses, each line as she sings it; every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`); the work's own sense of धारा in `glossary/hi.json`.
- **Recordings:** `audio/anuradha-paudwal/` (YouTube `Yb2GMwJyGnE`): live; hand-checked starts in `fixes.md`.

Verse types: टेक (refrain, `tek`, shown at the start and, as she sings it differently at the end, once more there as `aarti.tek2`, although it is also sung after every stanza) and पद (stanza, `pad`); the Mānas's own types (`cau`, `cha`, `do`, `so`) where a text uses them. The folder's format: `tools/works/README.md`.
