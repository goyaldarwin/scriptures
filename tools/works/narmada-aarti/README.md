# ॐ जय जगदानन्दी (Om Jai Jagadanandi)

The āratī of the river Narmadā (Revā) as mother, in Hindi (`hi`).

- **Text** (`text.txt`): ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, p. 265), checked against Drik Panchang. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.
- **Poet:** the last stanza names Shivānanda Svāmī (भजत शिवानंद स्वामी).

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Om Jai Jagadanandi) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 6 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
