# जय महावीर प्रभो (Jai Mahavir Prabho)

The āratī of Bhagavān Mahāvīra, in Hindi (`hi`). Its last stanza names its poet: ज्ञानमुनि (ज्ञानमुनि गुण गावे).

- **Text** (`text.txt`): ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, p. 145), checked against Drik Panchang. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Jai Mahavir Prabho) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 6 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
