# आरती श्री रामायण जी की (Aarti Shri Ramayan Ji Ki)

The āratī of the Rāmāyaṇa (the Rāmacaritamānasa), sung at the close of its reading, in Hindi (`hi`).

- **Text** (`text.txt`): Aarti Mala (page image i-364), checked against Drik Panchang. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Aarti Shri Ramayan Ji Ki) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 4 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), as the book prints it, and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
