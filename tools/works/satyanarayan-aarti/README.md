# जय लक्ष्मी रमणा (Jai Lakshmi Ramana)

The āratī of Satyanārāyaṇa (Viṣṇu, the lord of Lakṣmī), sung after the Satyanārāyaṇa vrata kathā, in Hindi (`hi`).

- **Text** (`text.txt`): Aarti Mala (page image i-329), checked against Drik Panchang. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** `audio/anuradha-paudwal/`: Anuradha Paudwal, the "Om Jai Jagdish Hare Aarti Sangrah" jukebox (YouTube `sd31yGqZFlA`), the track 27:15–33:12 (1635–1992 s); every verse sung, in the text's order. The starts come from the transcript, to be set by ear; hand-checked starts in `fixes.md`.
- **Poet:** the last stanza names Shivānanda Svāmī (कहत शिवानन्द स्वामी).

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Jai Lakshmi Ramana) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 8 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
