# जयति मंगलागार (Jayati Mangalagar)

The āratī of Hanumān, son of the Wind (Pavanasuta), in Hindi (`hi`), in a highly Sanskritised style.

- **Text** (`text.txt`): Drik Panchang, "Shri Pavanasuta Hanuman Aarti", the only witness; the āratī is not in ५१ चालीसा संग्रह आरतियों सहित. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Its last line names the poet Tulasī (तुलसि-मानस-रामपुर-विहारी).

Verse types: पद (stanza, `pad`); the page marks no refrain, so the āratī has no टेक. The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Jayati Mangalagar) › one section (`aarti`) › verses: 5 stanzas, each opening with जयति.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3").
- **Topics:** one, the āratī's title. **Reading plans:** none.
