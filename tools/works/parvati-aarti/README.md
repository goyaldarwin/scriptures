# जय पार्वती माता (Jai Parvati Mata)

The āratī of Pārvatī, in Hindi (`hi`).

- **Text** (`text.txt`): ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, p. 250), checked against Drik Panchang and Aarti Mala. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

The closing stanza begins श्री प्रताप आरती मैया की, which may carry the poet's name (Pratap); no witness says more.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Jai Parvati Mata) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 7 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
