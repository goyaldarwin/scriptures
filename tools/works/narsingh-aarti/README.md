# ॐ जय नरसिंह हरे (Om Jai Narsingh Hare)

The āratī of Bhagavān Nṛsiṁha, in Hindi (`hi`), sung to the tune of ॐ जय जगदीश हरे.

- **Text** (`text.txt`): Drik Panchang, "Narsingh Bhagwan Ki Aarti" (om-jai-narsingh-hare; the book has no copy of it). Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Om Jai Narsingh Hare) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 3 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
