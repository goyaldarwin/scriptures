# ॐ जय श्रीश्याम हरे (Om Jai Shri Shyam Hare)

The āratī of Śrī Śyāma, Khāṭū Śyāmajī, in Hindi with Rājasthānī forms (`hi`).

- **Text** (`text.txt`): Drik Panchang's version, the one its recording sings (an āratī follows its recording); the book's version (५१ चालीसा संग्रह आरतियों सहित, Randhir Prakashan, p. 156) is recorded in `reconciliation.md`, with every choice.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** `audio/spiritual-activity/`: Spiritual Activity (YouTube `JZmGQyKfonA`, "खाटू श्याम जी की आरती - ॐ जय श्री श्याम हरे - Om Jai Shree Shyam Hare - Shyam Janmotsav 2024"), its track 0:00–5:18 of the video (after 5:18: music). Starts read by hand on 5-s windows (`fixes.md`), on the to-check list for the owner's ear.
- **Poet:** the book's version names Dāsa Manohara (गावत दासमनोहर); the version sung has कहत भक्त जन.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Om Jai Shri Shyam Hare) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 7 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
