# Reconciliation: आरती श्रीकृष्ण कन्हैया की

## Witnesses
- **Drik Panchang (base):** Shri Krishna Kanhaiya Aarti (`hinduism/aarti/krishna/krishna-kanhaiya-aarti/printouts/drikpanchang/shri-krishna-kanhaiya-aarti.html`): five stanzas of four lines, each ending "…की" and followed by the refrain "आरती श्रीकृष्ण कन्हैया की", which the page prints only as that cue.
- **The book:** none. The āratī is not in ५१ चालीसा संग्रह आरतियों सहित (`hinduism/chalisa/books/aarti-chalisa-sangrah/`) or the other booklets; Drik Panchang is the only witness.
- **For doubtful readings:** web searches for the lines found no other site printing this āratī, so they settled nothing.

The rule: keep Drik Panchang; correct it only where it is clearly wrong. The library's writing standard (docs/PLAYBOOK.md §3): an āratī's verse has no comma (a pause within a line is a space); each printed line is a line, ending । and the stanza's last ॥N॥; the refrain (टेक) is shown once, first.

| Place | Base | Ours | Why |
|---|---|---|---|
| after every stanza | आरती श्रीकृष्ण कन्हैया की। (refrain cue) | the refrain, once, first (`aarti.tek`), ending ॥ | The page has the refrain only as the cue; the standard shows it once, as the first item. The first stanza (मथुरा कारागृह अवतारी) is a stanza, `aarti.pad1`. |
| every line | the printed commas (also inside lines: कटि काछनि, कर मुरलि; कौरव कालिय, कन्स; हिमकर भानु, कृसानु; कहुँ नृप कर, कहुँ गाय; कहुँ जागेस, बेद) | (none) | The standard. |
| stanza numbers | none | ॥१॥ … ॥५॥ | The standard. |
| stanza 2, line 3 | पूर्ण सरक ससि मुख लखि लाजै | पूर्ण सरद ससि मुख लखि लाजै | सरक is not a word; the image is the full autumn moon (सरद ससि) put to shame by his face. A one-letter typing slip. |
| stanza 3, line 2 | कन्स बिनासी | कंस बिनासी | Drik Panchang types the anusvāra as न्; the name is कंस. |

Open: stanza 4, line 3, कहुँ जागेस (`docs/reviews/krishna-kanhaiya-aarti-doubts.jsonl`); the text keeps the base.

Kept as the base has them: जसुदा, विहारी, छाजै, काछनि, मुरलि, पूर्ण, ससि, जितवैया, बिनासी, कृसानु प्रकासी, बसवैया, रन, जागेस, बेद, नचवैया, अगुन सगुन, बपु, रखवैया.
