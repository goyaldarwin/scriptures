# आरती श्रीकृष्ण कन्हैया की (Aarti Shri Krishna Kanhaiya Ki)

The āratī of Kṛṣṇa Kanhaiyā, in Hindi (`hi`; its words are Braj).

- **Text** (`text.txt`): Drik Panchang, Shri Krishna Kanhaiya Aarti; none of the printed booklets has it. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Aarti Shri Krishna Kanhaiya Ki) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`, one line) and 5 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
