# श्रीहनुमानचालीसा (Shri Hanuman Chalisa)

The Hanumān Chālīsā of Gosvāmī Tulasīdāsa, in Awadhi (`awa`): the Chālīsā of the Sundarakāṇḍa work, taken from it unchanged (`[take sundarkand …]`), so a correction there reaches this work at the next export.

- **Text** (`text.txt`): The Sundarakāṇḍa work (`tools/works/sundarkand/reconciliation.md`).
- **Meanings:** The Sundarakāṇḍa's own (`meanings/<lang>/scriptures.json` takes them).
- **Recordings:** `audio/ashwin-pathak/`: the Sundarakāṇḍa's recording, its timings taken for these verses (`source.json` → `take`).

Verse types: the Mānas's own (`do` dohā, `cau` chaupāī).

## Structure
- **Hierarchy:** one part (`chalisa`) › the Sundarakāṇḍa's three sections (the opening dohās, the forty chaupāīs, the closing dohā) › verses, with their ids, numbers and topics.
- **Topics:** the Sundarakāṇḍa's. **Reading plans:** none.
