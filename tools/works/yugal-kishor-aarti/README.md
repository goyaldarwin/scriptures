# आरती जुगल किशोर की कीजै (Aarti Jugal Kishor Ki Kijai)

The āratī of Śrī Kṛṣṇa with Rādhā (the Yugala Kiśora, the divine pair), in Hindi (`hi`).

- **Text** (`text.txt`): ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, p. 47, "आरती श्री गोपाल जी की"), checked against Drik Panchang (two pages) and Aarti Mala. Every choice: `reconciliation.md`.
- **Poet:** the signature line names परमानन्द स्वामी (stanza 8).
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Aarti Jugal Kishor Ki Kijai) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 8 stanzas, one per printed line of the book.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
