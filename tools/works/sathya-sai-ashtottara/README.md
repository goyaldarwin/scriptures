# श्री सत्यसाई अष्टोत्तर शतनामावलि (Śrī Satya Sāī Aṣṭottara Śatanāmāvali)

Shelf: हिन्दू धर्म › नामावलि › सत्य साई › श्री सत्यसाई अष्टोत्तर शतनामावलि
(`library/hinduism/namavali/sathya-sai/sathya-sai-ashtottara/`, work id `sathya-sai-ashtottara`). The 108 names of
Bhagavān Śrī Satya Sāī Bābā, in Sanskrit (`sa`): a nāmāvalī of the Sathya Sai tradition (20th century), each name
ॐ श्री साई … नमः, followed by the closing words. The name is spelt साई (Sāī) throughout, the owner's choice (`reconciliation.md`).

## Sources
- **Text** (`text.txt`): the owner's base, Bhakti Bharat's page *श्री सत्यसायि अष्टोत्तर शतनामावलि* (its spelling सायि; ours साई)
  (<https://www.bhaktibharat.com/mantra/bhagawan-sathya-sai-baba-108-names>, the owner's PDF of it with its text layer),
  checked name by name against the Sathya Sai Organisation's own list, the study guide *108 Mirrors* on sathyasai.org
  (parts 1–6, roman letters with diacritics). Every choice: `reconciliation.md`.
- **Recordings:** `audio/ashtotrashat-namavali/`: “Ashtotrashat Namavali, Sathya Sai Baba 108 Names” (YouTube `mLBceWHiVZA`;
  the reciter is not named), the whole video: the 108 names in this order, 0:02–6:43, no closing words (they stay untimed).
  The starts come from the transcript (`transcripts/`: Whisper small re-run over the whole recording in 4–9 s pieces with
  `tools/audio/transcribe_onnx.py`, as the first transcript heard only six lines; `"align": "anchors"`), with name 1's
  start checked by hand (`fixes.md`), to be set by ear.

Verse types: नाम (`nama`) and the closing words (`iti`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part › the section नामावलि (`nama`), the 108 names (`nama.n1` … `nama.n108`), and the closing
  words (`iti`).
- **Numbering:** a name's `n` is its place in the list, 1–108 (॥१॥ … ॥१०८॥), and it is cited by it (Name 5); the
  closing words have none and are named by their type.
- **Topics:** one, the title, at the first name. **Reading plans:** none.
