# Reconciliation: जय गोरख देवा

## Witnesses
- **The book (base):** ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, Haridwar, 2000), pp. 99–100, after the Gorakh Chālīsā; scriptures-data `hinduism/chalisa/books/aarti-chalisa-sangrah/` (page images i-098, i-099), read on the page images. Its order: the opening couplet (जय गोरख देवा), शीश जटा, गल सेली, नाथ निरंजन, ऋद्धि सिद्धि, अगम अगोचर, ब्रह्मा विष्णु, चारों युग, and the closing stanza with the poet's name (गुरु गोरख नाथ की आरती). The book prints no refrain cue after the stanzas. (Page image i-095 is a page of the Chālīsā, not of this āratī.)
- **Drik Panchang** (`hinduism/aarti/gorakhnath/gorakhnath-aarti/printouts/drikpanchang/shri-gorakha-aarti.html`): the same āratī, in the same order and the same words, each printed line broken in two.

The rule: keep the book; correct it only where it is clearly wrong. The library's writing standard (docs/PLAYBOOK.md §3): an āratī's verse has no comma; each line as the book prints it; the refrain (टेक) is shown once; stanzas numbered (॥१॥).

| Place | Book | Ours | Why |
|---|---|---|---|
| the opening couplet | the first couplet, unmarked | the refrain (`aarti.tek`) | The āratī's opening couplet, जय गोरख देवा, is its refrain, sung after each stanza. |
| stanza numbers | none | ॥१॥ … ॥८॥ | The standard. |

Kept as the book has them: every word; Drik Panchang does not differ from the book in any word.
