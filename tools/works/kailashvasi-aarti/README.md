# शीश गंग अर्धन्ग पार्वती (Shish Gang Ardhang Parvati)

The āratī of Śiva who dwells on Kailāsa (Kailāsavāsī), in Hindi (`hi`).

- **Text** (`text.txt`): Drik Panchang, "Lord Kailasavasi Aarti", the only witness; the āratī is not in ५१ चालीसा संग्रह आरतियों सहित. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: पद (stanza, `pad`); the page marks no refrain, so the āratī has no टेक. The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Shish Gang Ardhang Parvati) › one section (`aarti`) › verses: 10 stanzas, the first eight describing Kailāsa (rhyme -आसी), the last two a prayer (कैलासी काशी के वासी …).
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3").
- **Topics:** one, the āratī's title. **Reading plans:** none.
