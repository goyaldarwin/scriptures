# प्रभु श्री विश्वकर्मा घर आवो (Prabhu Shri Vishwakarma Ghar Aavo)

The āratī of Viśvakarmā, the divine architect and craftsman, in Hindi (`hi`).

- **Text** (`text.txt`): ५१ चालीसा संग्रह आरतियों सहित (Randhir Prakashan, p. 89), checked against Drik Panchang. Every choice: `reconciliation.md`.
- **Meanings:** Ours (`meanings/hi/scriptures.json`, `meanings/en/scriptures.json`).
- **Recordings:** none yet.

Verse types: टेक (refrain, `tek`, shown once at the start although it is sung after every stanza) and पद (stanza, `pad`). The folder's format: `tools/works/README.md`.

## Structure
- **Hierarchy:** one part (Prabhu Shri Vishwakarma Ghar Aavo) › one section (`aarti`) › verses: the refrain (`aarti.tek`, type `tek`) and 4 stanzas.
- **Numbering:** each stanza's `n` is its number (॥१॥ …), and it is cited by it ("Stanza 3"); the refrain has none.
- **Topics:** one, the āratī's title. **Reading plans:** none.
